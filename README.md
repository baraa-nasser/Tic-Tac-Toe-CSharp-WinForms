# 🎮 Tic-Tac-Toe Game

A simple **Tic-Tac-Toe (XO) game** built using **C# and Windows Forms**.

## 📌 About The Project

This is a two-player Tic-Tac-Toe game where players take turns playing as **X** and **O**.

The game checks all possible winning combinations (rows, columns, and diagonals) and determines whether **Player 1 wins, Player 2 wins, or the game ends in a draw**.

## ✨ Features

* 👥 Two-player gameplay
* ❌ Player 1 plays with X
* ⭕ Player 2 plays with O
* 🏆 Automatic winner detection
* 🤝 Draw detection
* 🎨 Highlights the winning combination
* 🔄 Restart Game button
* ⚠️ Prevents selecting an already occupied cell
* 🖥️ Simple Windows Forms interface

## 🎮 How to Play

1. Player 1 starts the game with **X**.
2. Player 2 plays with **O**.
3. Players take turns selecting an empty cell.
4. The first player to get three matching symbols in a row, column, or diagonal wins.
5. If all nine cells are filled without a winner, the game ends in a draw.
6. Click **Restart Game** to start a new game.
